# Wayland quickstart

Wayland: https://wayland.freedesktop.org/ — the display protocol
Hyprland, Sway, and GNOME/Mutter speak.

- Protocol XML: https://wayland.freedesktop.org/docs/html/
- Client lib: libwayland-client; helpers: wayland-scanner.
- Debug: `WAYLAND_DEBUG=1`, `wev` (event viewer), `wshowkeys`.
- See also: hyprland-template.
